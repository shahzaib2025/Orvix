# Website composition repetition: fix and observed results

## Confirmed faults and changes

- Fresh-site classification rejected any request containing the word `existing`. Consequently the exact benchmark brief, which asks to use the **existing preview tools**, bypassed recent-design comparison. Classification now distinguishes the requested website from tool instructions; repair/fidelity/component exceptions remain.
- Native and direct composition comparisons inherited the screenshot review system contract (`approved/needs_revision`) although their parser requires `distinct/repeated`. Both routes now use the correct separate comparison instructions.
- Confirmed repetition was advisory (`allowed: () => true`). File writes/edits, source-generating shell commands and preview startup now wait for a recorded acceptable changed proposal when recent notes exist. Read-only research and folder discovery remain available. Rejected proposals remain rejected after comparison exhaustion and across compatible checkpoints. Unavailable comparison is disclosed and permits construction without an originality claim.
- The direct system prompt explicitly called construction gates obsolete. That contradiction and advisory wording in Default/Medium were removed. Their aesthetic scope is preserved.
- Native style constraints are recorded separately from user permission decisions. One bounded continuation handles a native session ending after a direction denial. No extra settings, user approval stage, external skill discovery, database or polishing loop was added.

## MAX SVG enrichment

MAX now asks for at least four distinct SVG story treatments for roughly nine or ten full-site sections, distributed across hero, early, middle and late regions. Major story sections contribute a vector state or develop shared artwork; reading and controls may remain calm. Artwork and choreography are chosen for the subject, without a supplied scaffold. The motion reference covers ownership, handoffs, visibility, mobile/reduced motion, text semantics and actual remote-image loading. The execution reminder and existing visual-review criteria carry this standard. Default and Medium do not acquire the SVG minimum.
